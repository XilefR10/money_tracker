# About Money Tracker

**Money Tracker** is a modern, open-source personal finance management application built with Python and tkinter.

## 🎯 Mission

To provide an easy-to-use, lightweight alternative to complex financial software - making personal finance tracking accessible to everyone.

## 🌟 Highlights

- **Modern GUI** - Clean, organized interface with intuitive controls
- **Visual Analytics** - Charts, graphs, and timeline visualizations
- **Lightweight** - Minimal dependencies, runs anywhere Python is available
- **Portable** - Standalone Windows executable with no installation needed
- **Open Source** - MIT licensed, community-driven development
- **Data Privacy** - Your financial data stays local on your computer

## 📊 Key Features

| Feature | Description |
|---------|-------------|
| 💰 Income/Expense Tracking | Record all transactions with categories |
| 📈 Visual Charts | Bar and pie charts for spending analysis |
| ⏱️ Timeline View | See your balance change over time |
| 🏷️ Category Analysis | Group and analyze spending by category |
| 📊 Statistics | Track highest transactions and averages |
| 💾 Auto-Save | Automatic JSON-based data persistence |
| 🎨 Modern UI | Color-coded sections for easy navigation |

## 🚀 Quick Start

### For Users
```bash
# Download MoneyTracker.exe and run it
./MoneyTracker.exe
```

### For Developers
```bash
git clone https://github.com/XilefR10/money_tracker.git
cd money_tracker
pip install -r requirements.txt
python run.py
```

## 📦 Installation Methods

### Option 1: Pre-built Executable (Windows)
Simply download and run `MoneyTracker.exe` from the dist folder.

### Option 2: From Source
```bash
pip install -r requirements.txt
python run.py
```

### Option 3: As Python Package
```bash
pip install -e .

```
