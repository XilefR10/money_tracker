# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-01-08

### Added
- Initial release of Money Tracker
- Modern GUI application with tkinter
- Add income and expense entries with categories
- View financial totals and statistics
- Multiple visualization options:
  - Income vs Spending bar and pie charts
  - Money balance timeline graph
- Category-based analysis and filtering
- Highest spending/income tracking
- Average spending calculations by category
- Data persistence with JSON storage
- Organized project structure ready for GitHub
- Comprehensive documentation (README, CONTRIBUTING)
- Pre-built Windows executable with PyInstaller
- MIT License

### Features
- ✨ Beautiful, color-coded UI with organized sections
- 📊 Real-time financial charts and graphs
- 💾 Automatic data saving to JSON
- 🖱️ Intuitive modal dialogs for input
- 📁 Organized project structure (src/, data/)
- 📦 Standalone executable (.exe)
